# Images V4 : prompts Gemini

Chaque prompt est dans un bloc gris : sur GitHub (appli ou navigateur du téléphone), le bouton
« copier » en haut à droite du bloc copie tout le prompt. Un prompt = une image.

## Comment faire

1. Ouvre une NOUVELLE conversation Gemini par lot de personnage (une pour la fillette, une pour
   le grand-père...) : Gemini garde mieux le même visage et les mêmes habits d'une image à
   l'autre dans la même conversation. Pour les meubles, une conversation pour tout le lot A suffit.
2. Quand un prompt dit « joins l'image ... », ajoute cette image à ton message (trombone) avant
   d'envoyer. Elles sont dans le dépôt, dossier `docs/raw/V3` (sur GitHub : ouvrir l'image, puis
   « Download »). Si tu n'y arrives pas, envoie le prompt sans l'image : ça marche, en moins fidèle.
3. Vérifie le résultat : fond magenta uni partout, rien de coupé par le bord, pas de texte.
   Sinon, réponds dans Gemini : `Same image, but with a plain flat pure magenta background
   (#FF00FF) everywhere, and nothing cut by the edges.`
4. Télécharge l'image, puis sur GitHub : dossier `docs/raw/V4` > « Add file » > « Upload files ».
   **Pas besoin de renommer** : dépose les images d'un lot, dis-moi « lot B1 déposé », je les
   reconnais, je les renomme, je les détoure et je les branche dans le jeu.
5. Image ratée après 2 essais : passe à la suivante et dis-le moi, je trouverai une solution.

Ordre conseillé (le plus visible d'abord) : A (pharmacie), B (rescapés), C (zombies), D (héros).
Total : 46 images. Tu peux t'arrêter après n'importe quel lot, chacun sert seul.
